## Activate On GitHub

Committing this image or displaying it in the README does not configure the
repository's social preview. A repository administrator must:

1. Open [repository settings](https://github.com/robmoraes/engineering-playbook/settings).
2. Find **Social preview**, select **Edit**, then **Upload an image**.
3. Upload the JPEG in this directory.
4. Check the preview when sharing the public repository URL.

GitHub accepts PNG, JPG or GIF files under 1 MB, recommends 1280 by 640 pixels,
and shares custom preview images from public repositories. See
[GitHub's social preview documentation](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).

The image does not replace the repository name or description. Platforms
decide which metadata they display and may retain an older preview.

## Upwork And Other Portfolio Sites

Automatic link previews are platform-dependent. Upwork documents cases where
an external link works but its preview image cannot be generated. In that
case, upload the illustration as portfolio media and choose a suitable cover
instead of relying only on URL metadata.

Upwork recommends 1000 by 750 pixels for portfolio images. This GitHub asset
uses a different aspect ratio; inspect the platform's crop or create a
dedicated 4:3 variant before using it as an Upwork cover.

References:
[Upwork profile and portfolio help](https://support.upwork.com/hc/en-us/articles/360016144974-How-to-enhance-your-freelancer-profile),
[Upwork portfolio guide](https://www.upwork.com/resources/portfolio-guide).

```text
Primary request: Create a polished professional cover for the public documentation project Engineering Playbook, a practical reference for software architecture, DevOps, SRE, security and user experience.
Subject: An open engineering field manual with its pages thoughtfully unfolding into a coherent miniature arrangement of software architecture modules, connected delivery paths and a restrained interface panel. A unified editorial illustration of practical engineering knowledge, not a dashboard screenshot.
Style/medium: Sophisticated contemporary technical publishing illustration with careful geometric forms, tactile paper detail and subtle dimensionality. Crisp and composed, with strong readability at small thumbnail size. Restrained neutral tones and a solid background.
Composition: Balance a prominent title and the illustration with generous negative space. Keep all essential content at least 8 percent away from every edge. The title must dominate visually and remain readable on a small link card; no tiny annotations or clutter.
Text, exactly and only: "Engineering Playbook" as the large title, and "Standards, conventions and operational practices" as a smaller supporting line. Spell all text accurately; no other words or letters.
Mood: Credible, thoughtful, practical and human, suitable for an independent engineer's professional portfolio.
Constraints: Entire image is the finished flat cover, not a photo of a poster in a room. No platform or vendor logos, no personal contact details, no badges, no certificates, no invented metrics, no watermark, no transparency. Output a wide 2:1 image.
```
