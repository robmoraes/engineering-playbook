# Testing Templates

Copyable testing artifacts that apply
[Software Testing Standards](../../../testing/README.md).

## Available Templates

| File | Purpose |
| --- | --- |
| [Test Case](./test-case.md) | Concise reusable definition of context, action, data and expected behavior |

## Template Rules

- Preserve the distinction between test design and execution history.
- Remove optional sections that do not affect execution or interpretation.
- Replace every placeholder before marking a case active.
- Store cases near the feature or in the repository's established test
  management location.
- Do not include real credentials, production secrets or unnecessary personal
  data.

The template may be represented in Markdown or configured as equivalent fields
in a test management tool. Tool-specific configuration must preserve the
required information from
[Test Case Standards](../../../testing/test-case-standards.md).
